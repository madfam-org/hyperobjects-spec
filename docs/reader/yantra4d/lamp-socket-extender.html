Beneficio social

La base media Edison (E26/E27) es la interfaz de lámpara abierta de facto — miles de millones de portalámparas y bombillas la comparten. Extensores, adaptadores de base y carcasas de dispositivo impresos permiten bajar una bombilla en una pantalla poco profunda, adaptar una bombilla E26 a un casquillo E27 (o al revés), o convertir un portalámparas en soporte para un sensor, en vez de buscar una pieza propietaria. Name

E26/E27 Socket Extender

Societal benefit

The Edison medium screw base (E26/E27) is the de-facto open lamp interface — billions of sockets and bulbs worldwide share it. Printed extenders, base adapters and device shells let anyone lower a bulb into a shallow shade, fit an E26 bulb into an E27 fixture (or the reverse), or turn a lamp socket into a mount for a sensor or holder, instead of hunting for a proprietary part. The threaded interface interoperates with the lampshade and socket-adapter cartridges in the same commons family.
