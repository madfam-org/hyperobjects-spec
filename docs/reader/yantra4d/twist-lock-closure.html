Twist-Lock Closure

Societal benefit

A twist lock is the single component that decides whether a leather flap bag can be repaired: the plate is riveted, so when the turn-piece snaps the whole bag is usually discarded because the exact size is unbuyable. Printing the three parts to the existing rivet spacing returns a dead bag to service without re-punching the leather.
