Español

Nombre

Grulla de papel

Resumen

La orizuru tradicional, plegada paso a paso sobre estados planos con orden de capas: base preliminar, base de pájaro, pliegues para estrechar, pliegues invertidos interiores para el cuello, la cola y la cabeza, y las alas bajadas o abiertas. Cada estado se comprueba; el patrón de pliegues es la grulla terminada, desplegada.

English

Name

Paper crane

Summary

The traditional orizuru, folded move by move on layer-ordered flat states: preliminary base, bird base, narrowing folds, inside reverse folds for the neck, the tail and the head, and the wings brought down or spread. Every state is checked; the crease pattern is the finished crane unfolded.

Français

Nom

Grue en papier

Résumé

L'orizuru traditionnelle, pliée geste par geste sur des états à plat avec ordre des couches : base préliminaire, base de l'oiseau, plis d'affinage, plis inversés intérieurs pour le cou, la queue et la tête, et les ailes rabattues ou déployées. Chaque état est vérifié ; le motif de plis est la grue terminée, dépliée.

Português

Nome

Grou de papel

Resumo

O orizuru tradicional, dobrado passo a passo sobre estados planos com ordem de camadas: base preliminar, base do pássaro, dobras para afinar, dobras invertidas internas para o pescoço, a cauda e a cabeça, e as asas baixadas ou abertas. Cada estado é verificado; o padrão de vincos é o grou acabado, desdobrado.
