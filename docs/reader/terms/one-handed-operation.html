Term

one-handed operation

Definition

The capability of a garment that can be fastened, unfastened or put on using one hand — the accessibility claim behind an adaptive cuff, a nursing clip and a magnetic placket. It is a claim about a sequence of movements, not about a component: a closure that a second hand has to steady is not one-handed however easy that closure is.

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

operação com uma só mão

Definição

A capacidade de uma peça que pode ser apertada, desapertada ou vestida com uma só mão — a afirmação de acessibilidade por trás de um punho adaptado, de um clipe de amamentação e de uma carcela magnética. É uma afirmação sobre uma sequência de gestos, não sobre um componente: um fecho que precisa de uma segunda mão para o segurar não é de uma mão, por mais fácil que seja.

Restricción

The garment must hold itself still while the one hand works, so the claim implies an anchor — a cuff that opens flat against a table, a band that stays put under tension — and a closure tested only on a table edge is a closure tested against the wrong body.
