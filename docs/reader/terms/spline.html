Term

spline

Definition

A CDG interface type: a repeated tooth or flute form running around a shaft or a wheel, by which two parts transmit rotation without slipping. The commons uses it for both halves of that idea — the involute tooth of a gear pair, and the fine serrated hub a hobby servo turns.

Termo

estriado

Definição

Tipo de interface CDG: uma forma de dente ou estria repetida em torno de um veio ou de uma roda, pela qual duas peças transmitem a rotação sem patinar. O comum usa-a para as duas metades dessa ideia: o dente de envolvente de um par de engrenagens e o cubo finamente estriado que um servo de modelismo faz girar.

Restricción

A tooth form is a triple — module (or pitch), pressure angle, and tooth count — or, for a proprietary series, the named series itself. Two parts mesh only when the whole triple agrees; an interface dimensioned by outside diameter alone names a wheel that will not run against anything.
