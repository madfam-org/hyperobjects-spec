Term

care code

Definition

A machine-readable instruction for how a cloth is to be washed, dried and pressed — `machine_wash_30c`, `tumble_dry_low`, `iron_high` — carried on the fabric card rather than printed only on a label. Written as a code so a platform can carry it through to whoever ends up owning the garment.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

código de conservação

Definição

Uma instrução legível por máquina sobre como lavar, secar e passar um tecido — `machine_wash_30c`, `tumble_dry_low`, `iron_high` — levada na ficha de tecido e não impressa apenas numa etiqueta. Escrita como código para que uma plataforma a possa transmitir a quem acabe por ser dono da peça.

Restricción

The care code and the shrinkage figure describe the same wash: a card that says machine-wash and declares no shrinkage is claiming a cloth that does not move, which for an unwashed natural fibre is a claim that will be falsified the first time it is worn and washed.
