Term

target part

Definition

The parameter through which a caller tells a multi-part cartridge which piece to render. It arrives as a bare global that the cartridge's code branches on, which makes it the one parameter whose value has to match an id declared elsewhere in the manifest: ask for a name the code does not branch on and the cartridge answers with its fallback body instead of an error.

Português

unmarked sem marca: a entrada não declara revisão

Termo

peça alvo

Definição

O parâmetro pelo qual quem invoca diz a um cartucho de várias partes qual peça renderizar. Chega como uma global nua sobre a qual o código do cartucho ramifica, o que faz dele o único parâmetro cujo valor tem de coincidir com um id declarado noutro ponto do manifesto: peça um nome sobre o qual o código não ramifica e o cartucho responde com o seu corpo de recurso em vez de com um erro.

Restricción

A single-part mode's id must equal its part id, because the mode id is what arrives as the target part. A mode named 'lid' whose part is 'lid_body' silently renders the fallback branch, and every check downstream passes on the wrong geometry.
