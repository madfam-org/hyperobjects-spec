Termo

licença do comum

Definição

A licença de hardware aberto sob a qual o objeto de um cartucho é publicado, declarada no manifesto como dado legível por máquina em vez de ficar entregue a um ficheiro do repositório. Os dois comuns publicam os seus objetos sob CERN-OHL-W-2.0, que é o que torna seguro construir uma ponte entre eles.

Restricción

A published open-hardware grant is irrevocable for the versions it was published on, so a 'pending' licence is a one-way door: fashion-cabinet's compliance lane treats the old `LicenseRef-FC1-pending` sentinel as a hard error from the ruling date forward.
