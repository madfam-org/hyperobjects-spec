Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

referência de norma

Definição

A norma publicada contra a qual uma interface é dimensionada, citada pelo seu identificador na própria interface — PCO 1881 para um gargalo, DIN EN 60715 para uma calha DIN, ISO 8559-1 para um perímetro do corpo. É o que permite a um cartucho encaixar em algo que ninguém neste comum fabricou, e o valor `internal` é a forma honesta de dizer que nenhuma norma se aplica.

Restricción

Cite the standard that governs the fit, not the family it belongs to: 'a metric thread' is not a specification and 'ISO 261 / ISO 965' is, and a cartridge citing the loose form is claiming an interoperability nobody can check.
