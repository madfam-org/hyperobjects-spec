Termo

unidade de parâmetro

Definição

A unidade em que se escreve o valor de um parâmetro: mm para comprimentos, deg para ângulos, count para um número inteiro de coisas, ratio para um fator adimensional, percent para 0–100. É opcional num parâmetro de manifesto; se faltar, a etiqueta é a única indicação da unidade.

Restricción

A unit states what the number means, it does not convert it: a slider labelled in inches with unit mm is a contradiction, and the unit wins.
