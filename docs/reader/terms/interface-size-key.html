Termo

chave de tamanho de interface

Definição

A chave do vocabulário interface-sizes que uma interface realiza: uma norma ou um padrão físico com nome, como nema-17-face ou stack-30.5x30.5-m3. Duas interfaces só podem acoplar quando as suas chaves de tamanho resolvidas são iguais, por isso a chave é o ajuste partilhado, levado pelos dois lados.

Restricción

A bore carries the key of the shaft it fits, not a key of its own diameter: equality is the mating rule, so two names for one fit would make a correct mate fail.
