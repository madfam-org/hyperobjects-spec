generated written by a drafting pass, not natively reviewed

Term

interface frame

Definition

Where an interface sits on its part: an origin, a unit normal pointing from the feature toward where the mating partner sits, and an in-plane x-axis orthogonal to the normal, in the part's model coordinates (mm). Components may be expressions over the part's parameters, so the frame follows them.

Termo

referencial de interface

Definição

Onde uma interface se situa na sua peça: uma origem, uma normal unitária que aponta do elemento para onde fica a peça parceira, e um eixo x no plano, ortogonal à normal, nas coordenadas de modelo da peça (mm). As componentes podem ser expressões sobre os parâmetros da peça, de modo que o referencial os acompanha.

Restricción

A frame is not trusted until the render-time frame gate has found a planar mating face at it; static checks prove only that it parses and evaluates.
