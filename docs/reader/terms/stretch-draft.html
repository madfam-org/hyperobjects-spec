Term

stretch draft

Definition

The capability of a draft whose geometry is computed against the fabric's stretch rather than against the body alone: the pattern is a function of how far the cloth will go, so the same cartridge in a 20%-stretch rib and in a 60%-stretch jersey is two different patterns for one garment.

tracé élastique

Définition

La capacité d'un tracé dont la géométrie est calculée d'après l'élasticité du tissu et non d'après le seul corps : le patron est fonction de ce que la maille peut donner, si bien que la même cartouche dans une côte à 20 % et dans un jersey à 60 % fait deux patrons différents pour un même vêtement.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

traçado elástico

Definição

A capacidade de um traçado cuja geometria é calculada contra a elasticidade do tecido e não apenas contra o corpo: o molde é função do quanto a malha dá, pelo que o mesmo cartucho num canelado de 20% e num jérsei de 60% são dois moldes diferentes para uma mesma peça.

Restricción

The stretch figure the draft uses must be the fabric card's measured value and not a class name: 'jersey' is not a number, and a pattern solved from an assumed stretch fits only the cloth that happened to be assumed.
