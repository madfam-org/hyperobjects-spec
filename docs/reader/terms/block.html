patrón base

Definición

Un patrón liso y sin estilo, ajustado a un cuerpo, a partir del cual se hacen después las prendas diseñadas — la forma que tiene todo el ajuste y nada del diseño. English

generated written by a drafting pass, not natively reviewed

Term

block (sloper)

Definition

A plain, unstyled pattern fitted to a body, from which designed garments are then made — the shape with all the fit in it and none of the design. In this commons a block is a cartridge in its own right, and its `block` domain is what says that its purpose is to be built on rather than worn.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

molde base

Definição

Um molde liso e sem estilo, ajustado a um corpo, a partir do qual se fazem depois as peças desenhadas — a forma que tem todo o ajuste e nada do desenho. Neste comum, um molde base é um cartucho por direito próprio, e o seu domínio `block` é o que diz que existe para se construir sobre ele e não para ser vestido.

Restricción

A block carries fit and nothing else, so every ease in it is wearing ease: design ease belongs to the garment drafted from it, and a block that already contains a silhouette hands that silhouette to everything built on it.
