Term

grid

Definition

A CDG interface type: a repeating array of features on a fixed pitch, so that any object built on the same pitch stacks, tiles or nests with any other. The pitch is the whole contract — a bin and a baseplate interoperate because both are drawn on the same module, not because either knows the other exists. This is the interface type that turns a set of unrelated objects into a system.

Termo

grelha

Definição

Tipo de interface CDG: um arranjo repetido de elementos com um passo fixo, de modo que qualquer objeto construído sobre esse mesmo passo se empilha, ladrilha ou encaixa com qualquer outro. O passo é todo o contrato: uma gaveta e uma base interoperam porque ambas estão traçadas sobre o mesmo módulo, não porque alguma saiba que a outra existe. É o tipo de interface que transforma um conjunto de objetos soltos num sistema.

Restricción

The pitch belongs to the standard, not to the object: a grid whose pitch is derived from the object's own dimensions interoperates with nothing, which is the failure mode a declared 'standard' field exists to make visible.
