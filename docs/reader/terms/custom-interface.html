Term

custom interface

Definition

The escape hatch of both interface vocabularies: a declared interface whose geometry is none of the named types. It still names a real mating region and still carries the parameters that dimension it, but it tells a consumer nothing typed about HOW to meet it — so everything a type would have said has to be said by the id, the label and the parameter list instead.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

interface à medida

Definição

A válvula de escape dos dois vocabulários de interface: uma interface declarada cuja geometria não é nenhum dos tipos nomeados. Continua a nomear uma região de acoplamento real e continua a levar os parâmetros que a dimensionam, mas nada diz de tipado a quem a consome sobre COMO acoplar-se — por isso tudo o que um tipo teria dito tem de ser dito pelo id, pela etiqueta e pela lista de parâmetros.

Restricción

A custom interface must carry parameters. With no type to lean on, the parameter list is the whole of what a consumer can check a fit against, and a `custom` interface declaring none names a mating region that nothing dimensions.
