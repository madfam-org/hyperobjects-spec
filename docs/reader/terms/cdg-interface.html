Term

CDG interface

Definition

A typed, parameterized declaration of the geometry by which one cartridge mates with another — the commons' unit of composability. A cartridge declares each interface with an id, a geometry type, the standard it follows (or 'internal'), and the manifest parameters that give the interface its dimensions. Two objects compose when they share an interface and their driving parameters agree; because the declaration is machine-readable, that agreement is checkable rather than hoped for.

Português

unmarked sem marca: a entrada não declara revisão

Termo

interface CDG

Definição

Declaração tipada e parametrizada da geometria pela qual um cartucho acopla com outro: a unidade de componibilidade do comum. Um cartucho declara cada interface com um id, um tipo de geometria, a norma que segue (ou 'internal') e os parâmetros do manifesto que lhe dão as dimensões. Dois objetos compõem-se quando partilham uma interface e os seus parâmetros regentes concordam; e como a declaração é legível por máquina, essa concordância verifica-se em vez de se supor.

Restricción

Every parameter an interface names must be a real parameter id of the same manifest — an interface that cites a parameter neither side has declares a fit nothing dimensions.
