Term

interface symmetry

Definition

The rotational symmetry order of an interface about its normal: 0 for continuous (a round shaft or bore), 1 for none, otherwise the number of equivalent orientations (4 for a square bolt pattern). A mate picks one orientation with a rotation index below the order, or with an angle when the order is 0.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

simetria de interface

Definição

A ordem de simetria rotacional de uma interface em torno da sua normal: 0 se contínua (um eixo ou furo redondo), 1 se não tem, e caso contrário o número de orientações equivalentes (4 para um padrão de furação quadrado). Um acoplamento escolhe uma orientação com um índice de rotação menor que a ordem, ou com um ângulo quando a ordem é 0.

Restricción

Symmetry describes the interface, not the part: an MGN12H block's top pattern is a 20 × 20 mm square and so has symmetry 4, even though the block fits its rail only two ways.
