Term

FEM mesh interface

Definition

A CDG interface type for the case where the fit is not a dimension but a simulated contact: the interface is declared as the mesh region a finite-element contact solver acts on, and whether two bodies meet correctly is a question answered by running the solve, not by comparing numbers in two manifests. It is the commons' one soft-robotics interface, and it is honest about being a different kind of claim.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

interface de malha FEM

Definição

Tipo de interface CDG para o caso em que o ajuste não é uma dimensão mas um contacto simulado: a interface é declarada como a região de malha sobre a qual atua um solucionador de contacto por elementos finitos, e saber se dois corpos se encontram corretamente é uma pergunta que se responde correndo o cálculo, não comparando números em dois manifestos. É a única interface de robótica mole do comum, e é honesta ao ser uma afirmação de outra natureza.

Restricción

A simulated contact is only a claim about the world if the solver is named. The one cartridge using this type names its solver in the interface's `standard` field, and an entry of this type that names none is stating a result nobody can reproduce.
