Term

made to measure

Definition

The capability of a garment cartridge to draft from a body's own measurements rather than from a size chart: the body values are parameters, and every piece is solved from them at render time. It is the soft commons' default claim — a garment that cannot be measured to a person is a garment in someone else's size.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

à medida

Definição

A capacidade de um cartucho de peça se traçar a partir das medidas do próprio corpo e não de uma tabela de tamanhos: os valores do corpo são parâmetros e cada peça é resolvida a partir deles no momento do render. É a afirmação por omissão do comum macio — uma peça que não pode ser medida a uma pessoa é uma peça do tamanho de outra.

Restricción

The claim is only true if the body values are real parameters of the manifest. Thirty-seven cartridges declare it FALSE — panels, notions and cloth-unit garments that are drafted to a bolt or a fixed size — and that false is a statement, which is why the flag is a boolean and not an omission.
