Term

notion

Definition

A small functional component a garment needs but is not made of — a snap, a buckle, a clip, an eyelet, a length of boning. In this commons a notion is a domain a cartridge can belong to, and it is also the block through which a garment names the printed hardware it uses instead of drawing it.

Termo

aviamento

Definição

Um pequeno componente funcional de que uma peça precisa mas de que não é feita — uma mola, uma fivela, um clipe, um ilhó, uma barbatana. Neste comum, um aviamento é um domínio a que um cartucho pode pertencer, e é também o bloco pelo qual uma peça nomeia a ferragem impressa que usa em vez de a desenhar.

Restricción

A notion is the one garment-side object that regularly has a solid twin, so it is where an identity record belongs: the same physical thing existing as a soft cartridge and a printed one is a pair to declare, not a duplicate to remove.
