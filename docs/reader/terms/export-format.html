export format

Definition

One of the file types a cartridge can be delivered in, declared in the manifest so a user knows before rendering whether the object can enter their tool chain. The list distinguishes mesh from solid: STL and 3MF carry triangles, STEP carries geometry a CAD program can still edit, and glTF carries something a browser can show.

Termo

formato de exportação

Definição

Um dos tipos de ficheiro em que um cartucho pode ser entregue, declarado no manifesto para que se saiba antes de renderizar se o objeto entra na cadeia de ferramentas de quem o usa. A lista distingue malha de sólido: STL e 3MF levam triângulos, STEP leva geometria que um CAD ainda pode editar, e glTF leva algo que um navegador consegue mostrar.

Restricción

A declared format is a claim the render can actually produce it: a STEP export from a mesh-only pipeline is a promise the cartridge cannot keep, and a mesh format is only honest if the mesh passes the watertight bar.
