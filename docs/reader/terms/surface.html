Term

surface

Definition

A CDG interface type: a named region of a body's outer form that is itself the interface — what mates against it does so by lying on it over an area, not by entering it. It is the type for the cases where the fit is a shape rather than a fastening: a body form's girth ring at a measured height, a bevel gear's pitch cone, a claw that cradles a ball.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

superfície

Definição

Tipo de interface CDG: uma região nomeada da forma exterior de um corpo que é, ela própria, a interface — o que com ela acopla fá-lo apoiando-se sobre ela numa área, não penetrando-a. É o tipo para os casos em que o ajuste é uma forma e não uma fixação: o anel de perímetro de um manequim a uma altura medida, o cone primitivo de uma engrenagem cónica, uma garra que embala uma bola.

Restricción

A surface interface must name the parameters that PLACE it as well as the ones that shape it — a girth ring is only checkable against a body measurement if the manifest says at what height it sits, and a pitch cone only meshes if the manifest says at what angle.
