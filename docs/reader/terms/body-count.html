Term

body count

Definition

How many separate connected solids a rendered mesh splits into. It is a cheap number that answers an expensive question: whether the cartridge produced the one object it meant to. A count above one is not automatically wrong — an assembly renders as several — but it is always something the author should have intended, and it is where a stray body or a detached feature shows up before anyone prints it.

Português

unmarked sem marca: a entrada não declara revisão

Termo

contagem de corpos

Definição

Em quantos sólidos conexos distintos se separa uma malha renderizada. É um número barato que responde a uma pergunta cara: se o cartucho produziu o único objeto que pretendia. Uma contagem maior do que um não está errada por si só — uma montagem renderiza-se em vários — mas tem de ser sempre algo que o autor quis, e é onde um corpo solto ou um elemento destacado aparece antes de alguém o imprimir.

Restricción

The split must not require its pieces to be watertight. Splitting watertight-only discards exactly the malformed bodies the count exists to find, and reports a broken cartridge as clean — a body of negative volume is an inverted shell that reads as geometry and prints as nothing.
