Term

preset

Definition

A named point in a cartridge's parameter space that a manifest ships as a starting place — the values a user actually clicks. A preset is a promise that the object works there, which is why the render lane replays every conformance check at each declared preset instead of only at the defaults.

Termo

predefinição

Definição

Um ponto nomeado no espaço de parâmetros de um cartucho que o manifesto publica como ponto de partida — os valores em que alguém realmente clica. Uma predefinição é uma promessa de que o objeto funciona ali, e é por isso que a via de render repete cada verificação de conformidade em cada predefinição declarada e não apenas nos valores por omissão.

Restricción

A preset that raises or produces broken geometry is a FAILURE with no calibration excuse — it is the existing bar evaluated somewhere new. A shipped preset of yantra4d/extrusion-hyperobject crashed the CAD kernel while the defaults render stayed green, which is the case that put presets in the lane.
