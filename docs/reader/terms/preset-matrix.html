matriz de preajustes

Definición

La segunda pasada del carril de render: cada comprobación de conformidad repetida en cada preajuste que declara un manifiesto, y no solo en los valores por defecto del cartucho. English

generated written by a drafting pass, not natively reviewed

Term

preset matrix

Definition

The render lane's second pass: every conformance check re-run at every preset a manifest declares, rather than only at the cartridge's defaults. It exists because the defaults are the one parameter point a user is least likely to keep, and a green run there says nothing about the point they will actually click.

Português

generated redigido por uma passagem de rascunho, sem revisão nativa

Termo

matriz de predefinições

Definição

A segunda passagem da via de render: cada verificação de conformidade repetida em cada predefinição que o manifesto declara, e não apenas nos valores por omissão do cartucho. Existe porque os valores por omissão são o ponto do espaço de parâmetros que menos provavelmente se mantém, e uma passagem verde ali nada diz sobre o ponto em que se vai realmente clicar.

Restricción

A preset that renders geometry IDENTICAL to the defaults while setting different values is a note, not a pass: either the values never reach the script or the manifest's declared defaults have drifted from the script's own fallbacks.
